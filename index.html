Introduction

Java is a versatile and widely-used programming language renowned for its simplicity, portability, and object-oriented approach. Developed by James Gosling and his team at Sun Microsystems (now owned by Oracle Corporation), Java was first released in 1995 and has since become one of the most popular programming languages in the world. One of the key strengths of Java lies in its "write once, run anywhere" principle, which enables developers to create applications that can run on any platform with a Java Virtual Machine (JVM). This platform independence is achieved by compiling Java code into bytecode, which can be executed on different operating systems without the need for recompilation.

Java vs. JavaScript

Java is a general-purpose language for enterprise applications and Android development, with strong typing. JavaScript is a scripting language for web development, focusing on interactivity. Java is statically typed and object-oriented, while JavaScript is dynamically typed and prototype-based. Java runs on JVM for platform independence, while JavaScript executes in web browsers.

Opening Lines

This is a simple program that will print Hello World

public class MyFirstJavaProgram { /* This is my first java program. * This will print 'Hello World' as the output */ public static void main(String []args) { System.out.println("Hello World"); // prints Hello World } }

To Run the program follow these steps:

  • Open notepad and add the code as above.
  • Save the file as: MyFirstJavaProgram.java.
  • Open a command prompt window and go to the directory where you saved the class. Assume it's C:\.
  • Type 'javac MyFirstJavaProgram.java' and press enter to compile your code.
  • Now, type ' java MyFirstJavaProgram ' to run your program.
  • You will be able to see ' Hello World ' printed on the window.
Basic Variables

In Java, variables are used to store and manipulate data during program execution. They hold values that can be of different types, such as integers, floating-point numbers, characters, booleans, or objects. Variable names must start with a letter, underscore (_), or dollar sign ($). They can include letters, digits, underscores, or dollar signs. Java is case-sensitive, so myVariable and myvariable are considered different variables.

If Else statements

In Java, the if-else statement is used to execute different blocks of code based on a condition. It allows you to create branching logic, where different paths of execution are taken depending on the evaluation of a boolean expression. Here's the basic syntax of the if-else statement:

if (condition) { // Code block executed if the condition is true } else { // Code block executed if the condition is false }

condition: A boolean expression that determines whether the code block inside the if statement should be executed or not. If the condition evaluates to true, the code block within the if statement is executed. Otherwise, if the condition evaluates to false, the code block within the else statement (if present) is executed.

if block: The code block that is executed if the condition is true. It is enclosed within curly braces {}. You can have multiple statements or even nested if-else statements inside the if block.

else block: The code block that is executed if the condition is false. It is also enclosed within curly braces {}. The else block is optional; you can omit it if you don't need to execute any code when the condition is false.

While Statements

In Java, the while statement is a control flow statement that allows you to repeatedly execute a block of code as long as a certain condition remains true. It provides a way to create loops that iterate until the condition evaluates to false. Here's the basic syntax of the while statement:

while (condition) { // Code block to be executed repeatedly }

condition: A boolean expression that determines whether the code block should be executed or not. The condition is evaluated before each iteration of the loop. If the condition evaluates to true, the code block is executed. If it evaluates to false, the loop is terminated, and the program continues with the next statement after the while block.

Code block: The block of code that is executed repeatedly as long as the condition is true. It is enclosed within curly braces {}. This block typically contains the statements you want to repeat, such as computations, input/output operations, or updates to variables used in the condition.

For Statements

In Java, the for statement is a control flow statement that allows you to iterate over a sequence of values or repeat a block of code a specified number of times. It provides a compact and structured way to perform repetitive tasks. The for statement has a flexible syntax that allows you to customize the initialization, condition, and update steps. Here's the basic syntax of the for statement:

for (initialization; condition; update) { // Code block to be executed repeatedly }

Initialization: The initialization step is executed only once before the loop starts. It typically initializes a loop control variable to a starting value. For example, int i = 0; initializes a loop control variable i to 0. The initialization step is optional and can be omitted if the loop control variable is already initialized.

Condition: The condition is a boolean expression that is evaluated before each iteration of the loop. If the condition evaluates to true, the code block is executed. If it evaluates to false, the loop is terminated, and the program continues with the next statement after the for loop. The loop will continue as long as the condition remains true. The condition is checked before each iteration, including the first iteration.

Update: The update step is executed at the end of each iteration, usually to update the loop control variable. It typically increments or decrements the loop control variable. For example, i++ increments i by 1 after each iteration. The update step is executed after each iteration, just before the condition is checked for the next iteration.

Code block: The block of code that is executed repeatedly as long as the condition is true. It is enclosed within curly braces {}. This block typically contains the statements you want to repeat, such as computations, input/output operations, or updates to variables used in the condition.

Methods

In Java, a method is a collection of statements that are grouped together to perform a specific task. Methods provide a way to organize code into reusable blocks, making programs modular and easier to maintain. A method is defined within a class and can be invoked or called from other parts of the program to execute its code. Here's an explanation of the key components and concepts related to Java methods:

A method signature consists of the method's name and the list of its parameters (if any). It uniquely identifies a method within a class.

returnType methodName(parameter1, parameter2, ...)

'returnType' is the data type of the value returned by the method after execution. If the method doesn't return anything, the void keyword is used. methodName is the identifier used to refer to the method. parameter1, parameter2, ... are optional input parameters that the method may require for its operation. Parameters are enclosed in parentheses () and separated by commas ,.
